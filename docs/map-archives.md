# CoastalCraft seasonal map repositories

The main website is CoastalCraft/coastalcraft.github.io.
Season maps live in separate CoastalCraft/season-N repositories, published by
GitHub Pages at https://coastalcraft.github.io/season-N/.

- Season 9: migrated existing uNmINeD export, all three dimensions and markers.
- Season 10: current uNmINeD export, spreadsheet markers, build radii and Spawn Town.
- Seasons 2–8: archive landing pages; map rendering/export still required.

World downloads were verified in H:\My Drive\Coastal Realm within their season
folders. They remain in Drive and have not been uploaded into these repositories.
The final Season 9 download is newer than the existing website map export; this
migration preserves the export and does not regenerate it.

Local checkouts:
- Main website: Unmined\CoastalCraftWebsite
- Season 9: Unmined\Coastal9
- Season 10: Unmined\Coastal10
- Seasons 2–8: Unmined\SeasonArchives\season-N

and was left untouched. Use the main website checkout above for website updates.

corresponding pages in season-9, retaining query strings and URL hashes.
